# AiXFreight app — UI kit

Control-tower web app for shippers: dashboard, shipment list, shipment detail with AI recommendations, and a new-quote flow. Navy sidebar + light content area. Built from the brand kit (uploads/AIXFreight-46c) — no product source existed, so layouts follow the design system's foundations.

Files: index.html (click-through), Shell.jsx (sidebar + topbar), Dashboard.jsx, Shipments.jsx, ShipmentDetail.jsx, NewQuote.jsx, data.js.
